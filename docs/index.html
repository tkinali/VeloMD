Features

Built around the way you write

The interface is one idea: your source on the left, the rendered page on the right. Everything else is speed and comfort — synchronized scrolling, line highlighting, search on both sides.

Split-pane live preview

Render as you type. Two-way synchronized scrolling and the cursor's line highlighted in orange in the preview — via a source-line map.

Tabs + hot-exit

Several files at once. Close and reopen the app: your tabs, the active tab, and unsaved buffer contents come right back.

Find & replace

Ctrl+F on either side: a find/replace bar in the editor, a counted search in the preview. Ctrl+Enter replaces all.

System fonts, themes

Font lists come live from fc-list — monospace only for the editor. Light/dark/system app theme, six preview themes.

Code blocks with a language picker

Pick Bash, Python, PHP, C, JS… from the toolbar's ``` ▾ menu; highlight.js colors your code.

Lightweight & offline

~600 KB of vendored JS on GTK4 + WebKit2GTK. No Electron, no Node, no internet required. A single install.sh.

Themes: GitHub Solarized Monokai Dracula Nord One Dark
Installation

One command, any distribution

The installer checks dependencies and installs them through your package manager if missing; it puts the velomd command and the application-menu entry in place.

bash
$ git clone https://github.com/tkinali/VeloMD.git
$ cd VeloMD
$ ./install.sh
✓ Python 3.14 found
✓ System dependencies already installed
✓ Command installed: ~/.local/bin/velomd
✓ Installation complete!
$ velomd NOTES.md
Shortcuts

Let your fingers memorize them

Ctrl + FSearch — editor (find & replace) when focused, preview otherwise
Ctrl + Shift + FOpen the find & replace bar focused on the Replace field
Ctrl + S / Ctrl + Shift + SSave / save as (autosave included)
Ctrl + T / Ctrl + WNew tab / close tab
Ctrl + B / I / KBold / italic / link
Ctrl + ,Settings — theme, language, fonts, autosave
Ctrl + = / - / 0Font size up / down / reset
